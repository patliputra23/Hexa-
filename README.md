# Lumen

Lumen is an original Android-first premium music app prototype built with Expo React Native and TypeScript. It includes a dark commercial UI, local demo auth, a fictional licensed catalog, player state, queue, favorites, playlists, downloads/offline metadata, release docs, and replaceable service interfaces.

## Run

```bash
npm install
npx expo start
```

Use Expo Go for general UI testing. Use an EAS development or preview Android build to validate sustained background playback and Android lock screen controls.

## Safety

- Demo tracks are generated original tones stored in `assets/audio`.
- No API keys or private credentials are included.
- `.env.example` documents public placeholders only.
