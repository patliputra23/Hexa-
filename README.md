# Lumen 🎧

Lumen is a modern cross-platform music streaming application built with React Native and Expo, designed to deliver a smooth, immersive, and premium listening experience.

The application combines a clean dark-themed interface with optimized audio playback, playlist management, offline storage, and responsive navigation to create a fast and elegant music environment across devices.

---

## Core Features

- High-quality audio playback
- Background music support
- Playlist & queue management
- Offline track availability
- Authentication flow
- Premium responsive UI
- Smooth animated interactions
- Cross-platform compatibility

---

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Expo Audio
- Zustand
- Async Storage
- Reanimated

---

## Architecture

Lumen follows a modular component-based architecture with centralized state management, optimized routing, and scalable folder organization for maintainability and performance.
