# Lumen Privacy Policy Placeholder

Last updated: May 6, 2026

Lumen is currently a demo music app prototype. This placeholder must be reviewed by legal counsel before public release.

## Data Collected

- Local account profile: name, email, and local demo session identifier.
- Local app activity: favorites, playlists, queue state, recently played tracks, settings, downloads metadata, and app logs.
- Optional analytics hooks: disabled by default and stored locally in this demo.

## Data Not Collected In This Demo

- No contacts.
- No microphone recordings.
- No precise location.
- No payment details.
- No private API keys.
- No copyrighted commercial audio assets.

## Offline Downloads

Lumen only allows offline caching for tracks marked as licensed demo tracks. In this prototype, bundled original demo audio remains packaged with the app, while download state is represented by local cache metadata.

- Replace local demo auth with a production auth provider and publish data retention terms.
- Document analytics vendors, crash reporting vendors, and support contact details.
- Add account deletion and data export instructions.
